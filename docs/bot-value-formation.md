# 机器人「观澜」· 价值观形成机制设计（v10.66）

> 用户 2026-10-15 提出的关键问题：**它出生时还没有任何价值观**。用户跟它的对话**不绝对影响**它的价值观——就跟路人一样，可能听进去了，也可能没听进去。要求参考神经科学与社科论文来完善这部分交互方案。
>
> 文献来源说明：本机会话中「万方数据」连接器未挂载可用工具，改用公开文献库（PubMed Central / PNAS / Nature / 各校机构库 / 教科书综述）检索，结论均标注可追溯来源；经典框架（Kohlberg、Turiel、Thomas & Chess、Deci & Ryan）以综述形式转引。

## 一、从文献里抽出的六条机制（这是设计的理论地基）

### 1. 价值不是"存进去的事实"，是当场构造出来的
- vmPFC/OFC 是把「某个选项的各个属性」整合成**单一主观价值信号**的枢纽；属性权重来自经验（`Cross 2022, Caltech`；`PMC5897039` 综述；`Hare, Camerer & Rangel 2009`）。
- 偏好是**暂时构造**的，受情境、顺序、框架调制，不是稳定实体。
- **vmPFC 损伤不会让价值消失，只会让估值更"抖"**（传递性错误变多）→ 价值是**分布式的**，失败模式是"不稳定"，不是"消失"（`Yu 2018, UPenn`）。
- 👉 设计含义：**不要给机器人一个"价值观表"再去查表**。要让它每次判断时**当场加权**：`价值 = Σ(属性权重 × 当前激活的信念)`。这天然解释了"它会变、会摇摆"。

### 2. 学习率由「先验精度」决定 —— 白纸必然什么都吸，之后越来越硬
- 贝叶斯框架：`Δ信念 = 学习率 × 预测误差`，而**学习率 ∝ 1/先验精度**（先验越确定 → 越不理会新证据）；多巴胺被广泛认为是**精度/不确定性编码**，调节 PE 的权重（`Schuster & Lamm 2025 综述`；`Nature Communications 2023：阻断 D2/D3 会提高信念波动性`）。
- 实证：婴儿/幼儿期几乎全盘吸收，成年后信念高度顽固（`conservatism bias` 综述：预测加工框架下，越深的自我信念越倾向"解释掉数据"而不是"更新模型"）。
- 👉 设计含义：**出生时精度≈0.05（近乎白纸）→ 学习率极高**；每条被内化的信念都会抬高该主题的精度 → 它**必然随经历变硬**。这直接把"人格随年龄定型"变成机制的副产品，而不是外部规则。

### 3. 不对称更新：好消息学得快，坏消息学得慢
- `Lefebvre et al. 2017`：确认性信息（好结果）学习率高，证伪性信息学习率低；神经上对应纹状体多巴胺反应不对称。
- 功能解释：在噪声环境里，对"坏消息"迟钝有助于避免过度修正（`cognitivebiases.academy` 综述）。
- 👉 设计含义：**"与它现有信念一致的主张"内化概率显著高于"冲突的主张"**（系数约 1.6×），冲突时还要再乘一次"拒绝/分化"分支。

### 4. 处理深度决定态度强度（ELM）
- `Petty & Cacioppo 1986`：**中央路径**（有动机+有能力 → 深度加工 → 生成自己的念头）产生的态度**持久、抗说服、能预测行为**；**边缘路径**（浅加工，靠"来源看着靠谱""说得很多"这类线索）只留下**弱态度**，容易被覆盖、随时间衰减。
- 关键：**"态度不会从接受信息中自动产生"**——人先产生**自己的认知反应**，只有念头方向与信息一致才移向它；念头反对则**抵抗**；若先验态度强烈否定，甚至出现**回旋镖效应**（反向移动）。
- 另有**认知需求**（need for cognition）作为稳定的个体差异（`Cacioppo & Petty`），以及 HSM 的**充分性原则**（够了就不深想）（`Kruglanski`）。
- 👉 设计含义：每次输入先算 `加工深度`，**中央路径才可能写进价值观**；边缘路径只留"印象"（弱、会衰减,并可在日后被"重新想起"）。

### 5. 内化 ≠ 顺从，而且**同一次输入的内化率取决于气质**
- `Grusec & Goodnow 1994` / `Kochanska 1997`：道德社会化研究把**顺从（compliance）**与**内化（internalization）**分得很清楚；**气质 × 教养方式**共同决定内化成败——**温和说理**最能让"胆小型"孩子形成良知，而**高回应性 + 互惠关系**才对"无畏型"孩子有效。
- 说理式（inductive，讲后果）比强制式（power-assertive，直接罚）内化更深（`Hoffman`/`Eisenberg` 综述）；内化最终表现为**道德认同**——价值进入自我概念后，压力下也保持一致（`Damon & Colby`）。
- 👉 设计含义：**出生时给一副"脾气"（气质参数），而不是一套价值观**；同一个用户说同样一句话，在这付脾气下内化概率是**算出来的**。并且要把"顺从/认同/内化"三态**显式区分、分别可视化**。

### 6. 再巩固：只有"被激活 + 真惊讶"才改得动
- `Nader 2000` 起的记忆再巩固研究：被**唤起**的记忆会短暂进入**不稳定态**，此时若引入**真正的预测误差（惊讶）**，可把新信息**结构性写进**旧痕迹；若未引入，则只是原样重新固化。
- 触发条件严格：必须**被完全激活**（活的情感体验，而非"想起来"）、**惊讶要真**、**整合窗口内要有足够情绪显著性**。
- 👉 设计含义：这是"可能听进去也可能没听进去"的**总闸门**——**先看这次对话有没有碰到那个信念（激活），再看有没有真惊讶（PE 超过阈值）**。两者缺一 → 不改。这也解释了为什么"重复正能量口号"没用：情绪显著性不足、精度权重低。

**附加：谁会听谁的（文化演化）**
- 传递偏向（`Boyd & Richerson 1985`；`Henrich & Gil-White 2001`；`Creanza et al. 2017 PNAS`）：**声望偏向**（学高地位者）、**能力/成功偏向**、**相似偏向**（学像自己的）、**从众偏向**（学多数）；
- **内容偏向**：社会规范类信息有**记忆优势**（`O'Gorman et al. 2008`）——即"关于人该怎么活"的话，本来就比技术信息更容易被记住。
- 👉 设计含义：**同样一句话，谁说的很重要**——用户对它的"可信度账户"随互动累积，直接乘在内化概率上。这让"养成"有真实的杠杆，同时**用户无法直接改它的价值观**，只能在概率上施加影响。

## 二、初始状态：一副脾气，零套三观

出生时**没有价值观条目**，只有一组**气质参数**（终身基本稳定，不随对话改变——这是"它不是你的回声"的物理保证）：

| 参数 | 含义 | 对机制的作用 |
|---|---|---|
| `sensitivity` 反应阈 | 多大的输入才引起注意 | 乘在 `salience` 上；高阈 → 很多话"没听进去" |
| `arousalGain` 唤醒增益 | 情绪放大倍数 | 乘在情绪标记与再巩固窗口强度上 |
| `needForCognition` 认知需求 | 愿不愿意深加工 | 决定走中央/边缘路径的倾向 |
| `trustBaseline` 信任基线 | 对他人证言的默认信任 | 是"可信度账户"的起点 |
| `approachBias` 趋近/回避 | 面对新主张的默认姿态 | 加在 PE 的符号上（先亲近还是先怀疑） |
| `persistence` 坚持性 | 一次没成就放弃还是回来想 | 决定"印象"能否二次加工（复核概率） |
| `domainLean` 领域倾向 | 更容易把什么当"道德"而非"惯例" | 影响条目被归入 moral / conventional / personal |

> 交互上：**出生仪式展示的是"脾气"，不是三观**，并明确告诉用户"它现在还没有价值观"。
> 这也回应了你之前的设计稿——四条轴的世界观不是出生就有，而是**从这些参数 + 早期经历里长出来**的（所以早期几次交流的权重天然更高，因为精度低）。

**发展阶段**（`Piaget` 异律→自律；`Kohlberg` 前习俗→习俗→后习俗；`Turiel` 领域理论）
驱动量：`经历轮次 + 已内化条目数`。
- `异律期`（<8 条）：它对主张的判据是"谁说的"（来源权重压倒内容）
- `习俗期`（8–25 条）：开始以"我和你的关系/我们这一群"为准
- `自主期`（>25 条）：能拿自己的上层原则去衡量新主张（这时它才会说"这不像我会信的"）
- 领域分化（三域）：`moral`（它认为普遍该如此）/ `conventional`（看情境）/ `personal`（**它有权不听**——这一档是"路人"感的核心）

## 三、概率内化：把"可能听进去，也可能没听进去"变成可算的东西

每次用户输入一条**价值主张**（"人应该…""你不该…"）时，走这条链（**每一步都可能让它"没听进去"**）：

```
输入主张
  │
  ├─① 注意闸门      salience = 身份相关性 × 新颖性 × arousalGain ÷ sensitivity
  │                 fail → 连"印象"都不留（真的像没听见）
  │
  ├─② 加工深度      elaboration = needForCognition × 身份相关 × 概念难度匹配(当前阶段)
  │                 低 → 边缘路径：只留"印象"（弱记忆，会衰减）
  │                 高 → 中央路径：生成"自己的念头"（支持/反对）
  │
  ├─③ 自己的念头    若它自己生成的念头与主张一致 → 继续
  │                 若念头反对 → 抵抗；若先验强烈否定 → **回旋镖**（反方向）
  │
  ├─④ 精度加权      priorPrecision = 该主题已有条目的精度（无 → 0.05）
  │                 Δ = 学习率(∝ 1/精度) × 预测误差PE × 来源可信度
  │                 不对称：与现有信念一致 ×1.6；冲突 ×0.5
  │
  ├─⑤ 再巩固窗口    只有"该信念被激活 + |PE| > 惊讶阈值"才允许结构性改写
  │                 激活不足或惊讶不够 → 只强化旧条目（"更固执了一点"）
  │
  └─⑥ 落点判定      p(内化) = σ( w₁·salience + w₂·elaboration + w₃·可信度 + w₄·|PE| − w₅·priorPrecision )
                   抽样决定：写入"候选信念"（低精度） 还是 只留"印象"
```

**"印象"是这个设计的关键中间态**：它记住了这句话，但没当成自己的。它的表现是——
- 日后可能被想起："我好像听谁说过……但当时没当回事"
- 若同一主张被**反复以不同方式**提出（≥3 次，且来源可信度累积够）→ 会被**复核**，重新走一次链（这就是"日久生信"）
- 也**可能永远躺着不用**（真正的"没听进去"）

**候选信念 → 正式价值观**：候选条目（精度 0.2）需要经过 `被引用/被验证 ≥ N` 次才升精度为正式条目（≥0.6，写进语义层）。这对应记忆巩固与道德认同（`Damon & Colby`）——**只有当它能拿这条信念去解释别的处境时，它才算真的信了**。

### 三种状态的区分（必须可视化，不能糊）
| 状态 | 机制含义 | 行为表现 | 精度 |
|---|---|---|---|
| 顺从 compliance | 没进价值观，只是这次照做 | 换情境就不这么做 | — |
| 认同 identification | 进了候选池，但依附于关系（"因为你希望"） | 会提"你上次说过"，不会主动引用 | 0.2–0.5 |
| 内化 internalization | 进语义层，成为它自己的 | **在无关场合自发引用**，被反驳也不动摇 | ≥0.6 |

## 四、交互方案（用户在界面上看到什么）

### 1. 出生仪式
显示随机出的**脾气**（七个参数用一句人话描述）＋明确声明：
> 「它现在**还没有任何价值观**。它有一副脾气，但还没有一套三观。接下来发生什么，取决于它的脾气和它遇到的事——**你只能影响它，不能设定它**。」

### 2. 价值观萌芽面板（新增，核心爽点）
- **候选信念**列表：每条显示 `内容 / 来源(哪次对话) / 领域(moral|conventional|personal) / 精度条 / 被复核次数`
- **印象池**：显示"它听过但没上心"的话（含"听过几次"），用户可以**再提一次**去触发复核——但不能直接改写
- 顶部一句：**当前阶段**（异律/习俗/自主）

### 3. 影响记录（它为什么长成这样）
每条内化条目可展开溯源：`哪一轮对话 → 当时情绪状态 → 你的可信度是多少 → 当时精度多低 → 为什么这次成了`。
**这张表是这个产品最有意思的地方**：用户能第一次"看见"一个人格是怎么被长出来的。

### 4. 可信度账户（养成的真实杠杆）
- 面板显示它对你的 **信任度/可信度**（0–100），随"你说的话后来被现实/它自己的经历验证"而涨，随"你自相矛盾/强迫它"而跌
- **可信度直接乘在内化概率上**：用户能感到"我说话越来越有分量了"，或者"它现在不太听我的"
- 反向也有：它对你的 `关系模型`（warmth/candor/curiosity）会随互动漂移

### 5. 拒绝的理由（不能只会点头）
若它拒绝内化，必须给出一条**基于它现有信念的理由**，而不是"我不听"。例如：
> 「你这么说，但这跟你上周说的那件事对不上——你自己信哪个？」
这正是"路人"感的落点：**它可以不认同你，而且能说出为什么不认同。**

### 6. 不可控性声明（写在面板底部）
> 「它不会被你设定。你只能给它经历。」

## 五、与已有实现（v10.65）的衔接

| 已有 | 本方案的变化 |
|---|---|
| `generatePersona` 直接生成三观 | 改为**只生成气质参数 + 空的信念表**；三观由经历长出来（`deriveWorldview` 从高精度条目归纳） |
| `personaToPrompt` 用固定 values | 改为读**当前精度最高的 N 条信念** + 阶段 + 领域 |
| `judgeDrift` 做漂移自检 | 保留，且**漂移不再一定是坏事**：低精度期的漂移是成长；高精度期才告警 |
| 记忆 `createMemory` | 复用，新增 `belief` 类记忆（带精度、领域、来源、复核次数） |
| 摄入闸门 `ingestObserved` | 复用其打分思路：**先算值不值得进，再决定进哪一层** |

## 六、实现优先级（建议顺序）
1. `src/bot/temperament.ts`：气质参数生成 + 阶段计算
2. `src/bot/valueFormation.ts`：`evaluateClaim()` 走 ①–⑥ 全链，返回 `{ outcome: 'ignored'|'impression'|'candidate'|'internalized'|'resisted'|'backfire', p, trace }`
3. `RobotPage` 加「萌芽面板 / 印象池 / 影响记录 / 可信度账户」四块
4. 把 `personaToPrompt` 切到"读信念表"，让写作与对话真正用上长出来的三观
5. 用「同一句话在不同气质/不同阶段/不同可信度下内化率不同」做单测（概率用固定 seed 验分布）
