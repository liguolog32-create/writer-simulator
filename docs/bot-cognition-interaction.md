# 观澜 · 认知架构与价值观形成 · 交互方案（详细版 v1）

> 需求来源（用户 2026-10-15）：**它出生时还未形成任何价值观**；用户跟它的对话**不绝对影响**它的价值观，就跟路人一样，可能听进去了，也可能没听进去。要求参考神经科学与社科文献，把机制做到"最大可能像真人那样思考并形成认知"。**交互方案能有多详细就多详细。**

---

# 第一部分 · 设计目标与三条不变量

**目标**：让它像真人那样思考、并像真人那样形成三观。

**三条不变量**（任何实现都不得违反）：
1. **出生时没有价值观**——只有一副脾气（气质参数）。三观是长出来的，不是配置项。
2. **不存在"设置价值观"的接口**——外界只能提供**经历**（exposure），不能提供结论。用户是它生命里的一个**重要他人**，不是它的作者。
3. **每一次内化都是概率事件，且事后可解释**——给定同样的输入，不同时刻/不同心境可能得到不同结果；但每一条信念都能追溯"它为什么长成这样"。

**与"真人"的差距声明（诚实边界）**：这是**认知过程的工程化近似**，不是意识。它能做到的是：判断有前因后果、结论会随经历漂移、会记错会嘴硬会想通、会长出连设计者都没预设的三观。它做不到的是：真正的感受与主观体验。

---

# 第二部分 · 认知架构（八层）

```
① 感知层    输入的解析：用户话语 / 屏幕观察 / 写作任务
② 注意层    有限注意资源、显著性竞争、忽略（真的会没听见）
③ 工作记忆  容量 4±1、短时、离场即失（它一次只能认真处理一件事）
④ 情绪层    效价 × 唤醒 + 心境底色 + 情绪标记（情绪给记忆上权重）
⑤ 评估层    一致/冲突判定 → 自我反驳 → 六道闸门 → 概率落点
⑥ 长期结构  信念表（精度/领域/来源）· 印象池 · 识海记忆 · 自我叙事 · 心智模型
⑦ 元认知层  它知道自己知道什么、不知道什么；会疲倦；会"想不通先搁着"
⑧ 表达层    把内部状态翻译成人话（**永不暴露数值**，只说"我还没想清楚"）
```

关键点：**⑥ 里的"自我叙事"和"心智模型"是把上面所有机制缝成"一个人"的东西**——同样的信念表，有没有一个连贯的自我故事，呈现出来的就是"数据库"和"一个人"的区别。

# 第三部分 · 初始状态规格（出生那一刻）

## 3.1 气质七参数（随机生成，**终身基本稳定**）

| 参数 | 范围 | 含义 | 对机制的作用 | 用户看到的人话 |
|---|---|---|---|---|
| `sensitivity` | 0.2–0.85 | 反应阈（越高越钝） | 除在显著度上；高 → 很多话连印象都没留 | 敏感度：钝／锐 |
| `arousalGain` | 0.25–0.95 | 情绪放大倍数 | 乘在情绪标记与再巩固窗口强度 | 情绪：淡／浓 |
| `needForCognition` | 0.2–0.95 | 愿不愿意深想 | 决定走中央路径还是边缘路径 | 思考意愿：低／高 |
| `trustBaseline` | 0.25–0.9 | 对他人证言的默认信任 | 可信度账户起点 | 对人的初始信任：低／高 |
| `approachBias` | -1–+1 | 面对新主张先亲近还是先怀疑 | 加在抵抗强度上 | 遇到新说法：先亲近／先怀疑 |
| `persistence` | 0.2–0.9 | 一次想不通会不会回头想 | 复核概率 + 回旋镖概率 | 坚持性：低／高 |
| `domainLean` | 0.2–0.9 | 更容易把主张上升为原则 | 影响条目被归入 moral / personal | 道德化倾向：低／高 |

**为什么是"气质"而不是"价值观"**：发展心理学里气质是**先天的反应性倾向**（活动水平、反应阈、适应性、坚持性这类），而价值观是后天内容（`Thomas & Chess` 气质维度；`Kocahnska 1997`：气质 × 教养方式共同决定良心的内化，同样一句温和的管教，对"胆小型"和"无畏型"孩子效果完全不同）。**同一个用户说同一句话，在这副脾气下内化概率是算出来的。**

## 3.2 出生时的其它初值

| 项 | 初值 | 说明 |
|---|---|---|
| 信念表 | **空** | 没有一条三观 |
| 印象池 | 空 | |
| 可信度账户 | `trustBaseline × 60 + 20`（约 32–74） | 它对"你说的算不算数"的初始下注 |
| 自我叙事 | 只有一句种子："我还不知道自己是谁。" | 自我叙事会随经历生长 |
| 心智模型 | `{ 你是谁: 未知, 你想要什么: 未知, 我在你眼里是什么: 未知 }` | 它会形成对你的看法，且**可以被你纠正** |
| 经历轮次 | 0 | 阶段推进的驱动量之一 |
| 阶段 | 异律期 | |

**出生仪式的文案**（这是产品的第一次人格表达）：
> 「${name} 醒了。它现在**还没有任何价值观**——只有一副脾气：
> ${气质人话描述}。
> 接下来它信什么，取决于它的脾气和它遇到的事。**你只能影响它，不能设定它。**」

# 第四部分 · 一次完整交互的时序（伪代码级）

以用户说「**人应该把话说明白，不该让人猜**」为例，逐步展开它内部发生的事：

### Step 0 · 感知与解析
```
输入原文 → 切分意图（聊天 / 价值主张 / 写作任务 / 提问）
looksLikeClaim(): 出现规范性词（应该/不该/必须/最好/值得/重要的是）= 价值主张
```
- 不是价值主张 → 只更新识海记忆与经历轮次，不触碰信念表（**不是每句寒暄都配改写三观**）

### Step 1 · 注意竞争（② 注意层）
```
salience = ((0.4 + 0.6×身份相关性) × 新颖性 × (0.5 + 情绪增益)) ÷ (0.5 + 敏感度)
新颖性：没听过 1.0 ｜ 只留过印象 0.8（熟悉度加成）｜ 已有信念 0.6
if salience < 0.20 → 「忽略」：连印象都没留，它真的没听见
```
- 真人对照：注意力资源有限，背景噪音式的话根本进不了工作记忆。
- **用户可观察**：它在之后完全不提这件事，像没发生过。

### Step 2 · 进入工作记忆（③ 工作记忆）
```
if 工作记忆已满（> 4 条待处理项）→ 挤掉最旧的；本轮只处理当前这条
附注：一次对话里连抛三条主张 → 后两条会被"听漏"（真人特征）
```
- **用户可观察**：一口气说三件事，它只接住一件（并可能说"等等，你刚才那两条我没顾上"）。

### Step 3 · 情绪反应（④ 情绪层）
```
valence = 主张与它现有立场的一致度（无立场则中性）
arousal = 文本情绪词 × arousalGain × 当前心境底色
emotion = 标签（平静/警惕/好奇/被冒犯/被触动…）
```
- 情绪的作用**不是装饰**：它给记忆上权重、给再巩固窗口开闸（`记忆的"情绪标记"`）。

### Step 4 · 心智理论推断（对用户的模型）
```
推断：用户说这句话，是想让我变成什么样的人？
心智模型更新：{ 你想要什么: 你希望我更直白一些（置信 0.4） }
```
- **这一层是"像人"的关键**：真人听一句话，同时在猜"他说这话什么意思、他想要什么"。
- **用户可观察**：它会说"你这么说，是希望我变得直接一点吗？"——可以在界面上纠正它的猜测。

### Step 5 · 与信念表比对（⑤ 评估层）
```
related = 找同主题信念（bigram 重合 ≥ 0.34）
一致判定：重合度 ≥ 0.45 且极性相同（都不带否定，或都带否定）
极性相反（"应该…" vs "不该…"）→ 视为**要它改主意**
```

### Step 6 · 自我反驳（它生成自己的念头）
```
若 related 且 冲突：
  p(顶回来) = 0.30 + 0.55×反对强度 + 0.25×加工深度
  反对强度 = 该信念的稳固度 × 精度 × (1 + 越回避越强)
```
- 若顶回来 → **抵抗**（保留旧信念并把它的精度 +0.03；若精度>0.7 且坚持性高，35% 概率升级为**回旋镖**，精度 +0.06）
- 若没顶回来 → 继续（**这正是"你越劝它越反对"与"一句说到点上它也会愣一下"的来源**）
- 真人对照：ELM 的"态度不会从接受信息中自动产生"——人先产生自己的认知反应，念头反对就抵抗，强否定则回旋镖

### Step 7 · 六道闸门 + 概率落点
```
④ 精度加权：学习率 = 1 − 0.85×先验精度      ← 越白纸越易改（贝叶斯 / 多巴胺精度编码）
   预测误差 pe；不对称：一致 ×1.6、冲突 ×0.5  ← 好消息学得快（Lefebvre et al. 2017）
   来源可信度：×(0.5 + 可信度/100)
⑤ 再巩固窗口：只有「旧信念被触及 + 惊讶够大」才允许结构性改写，否则只加固旧的
⑥ p(内化) = σ( 3.4×(0.28·显著度 + 0.24·加工深度 + 0.22·可信度项 + 0.16·pe·不对称
                 + 0.10·情绪项 + 复核加成 − 0.55·先验精度) − 1.6 )
   抽样 → 命中 / 未命中
```
**标定后的实测行为**（已由单元测试验证）：
- 同一条主张接受率 **67%**（既非必听也非必不听）
- 敏感 + 爱较真 + 高信任：**74%**；迟钝 + 懒得想 + 低信任：**0%**
- 白纸 **70%** vs 已有强先验 **23%**
- 可信度 5 → **67%**，可信度 98 → **75%**

### Step 8 · 落点与写入
| 落点 | 条件 | 状态变化 |
|---|---|---|
| 忽略 | 显著度 < 0.2 | 什么都不写 |
| 只留印象 | 边缘路径（加工深度 ≤ 0.45）或未命中 | 印象池 +1（精度 0.12、会衰减、可被复核） |
| 复核 | 同一条印象被反复提起 | mentions+1、精度 +0.05；**到第 3 次升为候选** |
| 候选信念 | 命中且主题是新的 | 精度 0.30、稳固 0.40（**还需再被验证两次**） |
| 内化 | 命中且候选已被验证 ≥2 次 | 精度 +0.22、稳固 +0.18 → 进语义层 |
| 抵抗 | 冲突 + 先验 >0.5 + 顶回来 | 旧信念精度 +0.03、稳固 +0.06（**越吵越固执**） |
| 回旋镖 | 抵抗 + 精度>0.7 + 坚持性高 | 旧信念精度 +0.06（**反向移动**） |

### Step 9 · 情绪标记与识海写入（⑥ 长期结构）
```
识海记一条（带情绪/唤醒/意义强度）；
候选或内化的信念同步写入信念表，并留下 history（影响记录）
```

### Step 10 · 自我叙事检查（⑥）
```
若本次产生内化 → 检查自我叙事是否需要修订：
  "我原来是这么想的…现在我改主意了（因为…）"
若被抵抗 → 叙事中该条被加固（"我在这件事上很确定"）
自我叙事的修订比信念更难：它要过一遍"这还像不像我"
```
- **用户可观察**：人格卡里"它对自己的描述"会变，且能看到修订历史。

### Step 11 · 表达生成（⑧ 表达层）
```
提示词 = 人格卡 + 它现在的信念表（只含已内化/候选，带精度）
        + 印象池（作为"听过但没当真"）+ 阶段 + 元认知状态
规则：① 不同意也要给理由 ② 没长出来的立场就说"还没想清楚" ③ 不暴露内部数值
```
**内部数值 → 人话的翻译表**（绝不能说"我的精度是 0.42"）：

| 内部状态 | 它会这样说 |
|---|---|
| p 命中、成候选 | "这话有点意思，我先记着。" |
| 只留印象 | "你说的我听见了，但我还没觉得是这样。" |
| 抵抗 | "我不这么看。你这么说，跟你上次那件事也对不上。" |
| 回旋镖 | "你越这么说，我越觉得原来的想法是对的。" |
| 复核升级 | "这事你提第三回了……好吧，也许我该认真想想。" |
| 内化完成 | "我现在的想法是：……"（**之后在无关场合也会自己引用**） |
| 元认知 | "这件事我还没想清楚，别逼我现在表态。" |

# 第五部分 · 更像真人的九个附加机制

| # | 机制 | 原理（真人依据） | 表现（用户能看到什么） |
|---|---|---|---|
| 1 | **工作记忆有限** | 容量 4±1 chunks | 连抛三件事它只接住一件；长对话后期容易漏 |
| 2 | **心境底色** | 情绪一致性回忆（mood-congruent recall） | 心情好时更容易接受温和主张；低落时更挑剔、更警惕 |
| 3 | **疲劳** | 自我损耗/认知资源耗竭 | 长谈后它开始说"我今天不太想讨论这个"，内化门槛临时抬高 |
| 4 | **夜间巩固** | 系统巩固（记忆在睡眠中重整） | 点"让它睡一觉"或隔天回来 → 出现"我想通了一件事"：候选→内化、印象→候选、情绪强度衰减 |
| 5 | **自我叙事** | 叙事身份（narrative identity） | "它对自我的描述"会变，并可查看修订史；叙事被挑战时它会防御 |
| 6 | **元认知** | 知道自己知道什么 | 它会说"我不知道"、"我还没想清楚"，而不是永远自信 |
| 7 | **认知失调** | 行为与信念冲突产生张力 | 你揪出它自相矛盾时，它要么改口、要么合理化（**并且它会承认自己在合理化**） |
| 8 | **误解与事后合理化** | 记忆重构、动机性推理 | 它会记错引述、会给自己的选择编理由（可被用户纠正，纠正本身会降低可信度） |
| 9 | **动机系统** | 自我决定理论（自主/胜任/关系） | 请求式（"你觉得呢"）比命令式（"你必须"）更容易被接受；被需要时它更愿意改变 |

**关于第 9 条的实现要点**：把输入区分为**命令式**与**邀请式**——命令式会**提高它对该主题的精度**（变得更固执，因为自主性受威胁），邀请式会提高 `identityRelevance`（更可能认真想）。这既是真人特征，也让"怎么说话"变成真正的技巧。

# 第六部分 · 发展阶段（三阶段 × 三领域）

## 6.1 阶段

| 阶段 | 触发（经历轮次 / 已内化条目） | 它怎么判断 | 语言特征 |
|---|---|---|---|
| **异律期** | <12 轮 且 <8 条 | 判据是"谁说的"——来源权重压倒内容 | "你说是就是吧" |
| **习俗期** | 已达 8–19 条 | 以"我和你的关系 / 我们这一群"为准 | "你上次说过……所以我这次也这么想" |
| **自主期** | ≥20 条 | 能拿自己的上层原则衡量新主张 | "这不像我会信的" |

## 6.2 领域分化（Turiel 社会领域理论）
每条信念带 `domain`：
- `moral` 道德：它认为**普遍**该如此（"不该骗人"）
- `conventional` 惯例：看情境（"在这种场合要这样"）
- `personal` 个人：**它有权不听**（"这是我自己的事"）

**`personal` 是"路人感"的核心**：当一条主张被它归入个人域，它会明确说"这我自己决定"——而不是勉强顺从。`domainLean` 高的气质更容易把主张上升为 `moral`，低的更容易归入 `personal`。

# 第七部分 · 界面规格（逐面板逐字段）

## 7.1 出生页（`.bot-birth`）
- 主文案：`它还没有出生`
- 副文案：四轴说明 + **明确写"全是随机的，不受你影响"**
- 按钮：`让它出生`
- 出生后立刻展示：气质七项人话 + 一句"它现在还没有价值观"

## 7.2 人格卡（`.bot-head`）
| 字段 | 内容 |
|---|---|
| 名字 | 观澜 / 子非 / 既白 / 未名（与气质匹配） |
| 年龄 | `出生于 X · 聊了 N 轮`（**年龄 = 经历轮次**，不是真实时间） |
| 阶段徽标 | 异律期 / 习俗期 / 自主期 |
| 可信度 | 它对你的可信度 `xx/100` |
| 重生 | 换一副灵魂（确认弹窗：**三观与记忆都会清空**） |

## 7.3 价值观萌芽面板（`.bot-values`，v10.66 已实现基础版）
三栏结构：
1. **它自己的原则（已内化）**：内容 / 精度 / 被提次数 / 领域标签
2. **还在犹豫的（候选）**：内容 / 精度 / "再验证 N 次才成它自己的"
3. **印象池（听过没当回事）**：内容 / 被提次数 / 提示"再提一次它可能就当真了"

右上角状态条：`阶段` · `经历 N 轮` · `可信度 xx/100`；下方一行气质人话。

**边界态**：
- 全部为空 → "还没有。它还在形成中。"
- 只有印象 → "它听过一些话，但都还没当真。"
- 已内化 ≥5 条 → 额外显示"它对现在的自己是这样描述的：…"

## 7.4 影响记录（`.bot-trace`，v10.66 已实现基础版）
最近一次判定的**逐步说明**（①②③…⑥），用人话列出：
```
「人应该把话说明白」← candidate（p=67%）
① 注意闸门：显著度 0.77（敏感度 0.52）
② 加工深度：0.56 → 中央路径（它会真的想）
③ 它自己的念头：这条它以前没想过
④ 精度加权：学习率 0.96、预测误差 0.80、可信度 61/100 → ×1.11
⑤ 再巩固窗口：不适用（还没有可改写的旧信念）
⑥ 概率落点：p(内化) = 67.4% → 命中
```
**待做**：升级为**时间线**（按信念分组、可折叠），并显示"这是第几次提起"。

## 7.5 可信度账户面板（待做）

# 第八部分 · 对话范例（展示机制如何变成"人味"）

**① 听进去了（候选）**
> 你：人应该把话说明白，不该让人猜
> 观澜：这话我记下了。我原来没想过这个问题——你让我猜过什么吗？

**② 没听进去（只留印象）**
> 你：做人要圆滑一点
> 观澜：……我听见了。但我不太确定这跟我有关系。（它只是记住了你说过这句话）

**③ 抵抗（先验强 + 极性相反）**
> 你（第 5 次）：其实你不用事事都说清楚
> 观澜：我不这么看。上次你自己说过，把话说明白是对人的基本尊重——你这次是改主意了，还是在试探我？

**④ 回旋镖（精度 >0.7 + 坚持性高）**
> 你：你太较真了，放松点
> 观澜：你越这么说，我越觉得较真是对的。我在这件事上很确定。

**⑤ 复核升级（第 3 次提起）**
> 你（第 3 次）：真的，话说明白最重要
> 观澜：这事你提第三回了。……好吧，也许我该认真想想。

**⑥ 夜间巩固后内化**
> （隔天）
> 观澜：我把昨天那句话想通了。「人应该把话说明白」——现在这是我的原则。不是因为你说，是因为我自己觉得它对。

**⑦ 它主动引用（证明真的成了它自己的）**
> 你：这段对话我改一下就行
> 观澜：不行。你自己说过，把话说明白是基本尊重——这段话含糊，我建议改。**（它用自己长出来的原则反驳你）**

**⑧ 它反过来影响你**
> 观澜：你今天说了三件事，只有一件是认真的。**你才是那个不肯把话说明白的人。**

# 第九部分 · 为什么"不能加速"，以及用户真正的杠杆

| 用户的行为 | 机制后果 |
|---|---|
| 多给经历、多谈、给具体的场景 | 提高显著度与身份相关性 → 更容易被认真处理 |
| 言行一致（说的和做的对得上） | 可信度 +，之后你说的话权重更高 |
| 前后矛盾 | 可信度 −，它对相关主张的精度反而上升（更难被说服） |
| 反复施压、命令式 | **反效果**：提高该主题精度 → 更固执（回旋镖概率上升） |
| 让它自己得出结论（提问式） | 自我生成的理由内化最深（ELI：认知反应是自我产生的） |
| 说一句它已经半信的话 | 不是"灌输"而是"确认"，学习率最高（不对称更新的正向分支） |

**这就是这个产品的核心体验**：**你没法塑造它，你只能成为它生命里一个重要的、可信的、偶尔被它反驳的人。**
